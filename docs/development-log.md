## 6. 接续开发检查与记录

开始时读本文件和架构说明，核对源码与本地运行状态。`./start.sh --help` 查看启动方式；已有服务需更新时在原终端 Ctrl+C 停止。不要删除 data 或浏览器自选获得干净测试状态，需要隔离就用临时数据库和独立浏览器环境。

```bash
.venv/bin/python -m pytest -q
node --check frontend/app.js
./start.sh --reload
```

按改动检查 live 日期/来源、短窗口/缺字段、失败退真实缓存、demo 标识、页面和 CSV 一致、手机布局。实时验证与离线测试分开记录，限流遵守冷却。
