# 观市 · A 股行情工作台

个人基金投资者使用的行情查询工具，可查看大盘成交额／量、融资融券、板块快照、行业／主题指数和 ETF 走势，支持自选、资产对比与 CSV 导出。

## 一键启动

需要 Python 3.11 或以上；当前验证环境为 Python 3.13。首次安装依赖和查询真实行情需要网络。macOS / Linux 在项目目录运行：

```bash
./start.sh
```

脚本自动创建 `.venv`、安装缺失依赖并启动服务。终端出现 `Uvicorn running` 后，打开 **http://127.0.0.1:8080**。按 `Ctrl+C` 停止。

端口占用时使用 `PORT=8081 ./start.sh`。查看其他选项：`./start.sh --help`。

## 如何使用

- **市场总览**：查看成交额、成交量和两融趋势；默认近 40 个交易日，约两个月，可切换 20 / 60 日。
- **板块观察**：搜索行业／概念快照；上方 6 个行业／主题指数可比较近期涨跌和成交变化，点击查看历史。
- **指数与 ETF**：按名称或六位代码搜索，查看价格、均线和量价指标；点击星标加入自选，搜索另一资产进行对比。
- **我的自选**：汇总关注资产，自选保存在当前浏览器。
- **导出**：详情页导出每日数据；两融、指数概览和资产对比分别有自己的导出按钮。
- **数据状态**：查看来源状态；右上角可切换演示模式，演示数据仅用于体验功能。

请以模块显示的**数据截至日期**为准。行情可能延迟，盘中日线可能未完成；ETF 区间涨跌未计分红。大盘成交口径为沪深综指，含 B 股、不含北交所。东方财富板块历史目前受限流影响，6 个行业／主题指数仅覆盖各自成分证券。工具提供信息与统计，供你自行判断。
